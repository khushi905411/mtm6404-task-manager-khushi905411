## ✅ Project Overview

This is the **Iteration 1** of my Capstone Project — a static Task Manager web application built using **React 18 via CDN**. This version focuses on UI components, layout structure, and responsive design.

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Manual styling with custom color palette)
- **React 18** (via CDN)
- Babel (for JSX support)
- JavaScript (static components only)

---

## 📋 Features Implemented

| Feature                      | Description |
|-----------------------------|-------------|
| ✅ React 18 via CDN         | Set up without any framework or build tools |
| ✅ JSX Support              | Enabled using Babel in the browser |
| ✅ Responsive Design        | Fully responsive layout using CSS |
| ✅ Header Component         | Displays the app title |
| ✅ Navigation Component     | Includes Home, Tasks, About, Contact links |
| ✅ Task List                | Displays a list of 6 tasks |
| ✅ Buttons (Add/Edit/Remove)| Present in each task (static only) |
| ✅ Footer Component         | Footer with copyright |
| ✅ Color Palette            | Custom colors: `#EA2F14`, `#E6521F`, `#FB9E3A`, `#FCEF91` |

🖥️ How to Run

> No installation or build steps are required.

### Option 1: Open directly
- Double-click `index.html` to open in your browser.

### Option 2: Use Live Server (VS Code)
- Open the folder in VS Code
- Click **Go Live** (bottom right)
- View your app at `http://localhost:5500` or similar
